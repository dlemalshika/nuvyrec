# Nuvyrec v1.0.0 — First Windows release

Nuvyrec's first release packages the native Windows screen recorder with its
own installer, neon logo and GitHub update checker. This is a Windows capture
alpha; see the included release-status document for validation and limitations.

## Download and install

Download **Nuvyrec-Windows-x64-v1.0.0-Setup.exe** and run it. The installer includes
the required runtime libraries, creates a Start Menu shortcut and offers an
optional Desktop shortcut. Flutter, Rust and FFmpeg do not need separate installs.
Alternatively, extract **Nuvyrec-Windows-x64-v1.0.0.zip** and run Nuvyrec.exe,
keeping the whole folder together. SHA256 files accompany both downloads.

Requires x64-compatible Windows 10 version 1903+ or Windows 11. This release is
unsigned, so Windows may show an unknown-publisher or SmartScreen warning.

## Included features

- Display, window and region recording, including Follow mouse for regions.
- Hardware encoder selection and resource presets with CPU fallback.
- System/microphone audio, webcam overlays, chroma key and annotations.
- Saved visual scenes and Cut / Fade-through-black transitions.
- Local recordings, replay history and export tools.
- RTMP/RTMPS multistream destinations sharing a single encoding pipeline.
- Dark/Light themes and daily idle GitHub update checks with manual Check now.

## Known limits

- This release provides Windows binaries; macOS/Android/iOS capture integration
  remains unfinished.
- Update notifications open GitHub release pages. Installation is manual.
- Real platform streaming, clean-machine compatibility and sustained performance
  across low-end hardware and 4K/120fps require further validation.
- Scenes share one capture source; multi-source scene graphs are not implemented.

Stop and save recording and exit Nuvyrec before installing another version.
Uninstall preserves existing recordings and user preferences.
